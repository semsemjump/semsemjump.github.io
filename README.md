# 셈셈 점프

자연수 사칙연산 문제를 풀고 정답 계단으로 폴짝 뛰어 우주까지 올라가는 레트로 픽셀 게임이에요.
만든이 빵쌤 (ppang_sem).

**게임 하러 가기 → https://semsemjump.github.io/**

휴대폰, 태블릿, 컴퓨터 브라우저에서 설치 없이 바로 할 수 있어요.

# 게임 설명서

## 어떻게 하나요?

1. 화면 위 간판에 문제가 나와요. 예: `7 × 8 = ?`
2. 캐릭터 왼쪽과 오른쪽에 계단이 하나씩 있고, 각 계단에 답이 적혀 있어요.
3. **정답이 적힌 쪽 계단을 밟으면** 한 층 올라가요.
4. **틀린 계단을 밟거나 시간 게이지가 다 닳으면** 떨어지고 게임이 끝나요. 떨어지면 그 문제의 정답을 보여줘요.
5. 맞힐 때마다 시간 게이지가 채워져요. 높이 올라갈수록 게이지가 조금씩 더 빨리 줄어요(최대 40%).

오를수록 배경이 **낮 → 노을 → 밤 → 우주**로 바뀌고, 계단도 **잔디 → 모래 → 눈**으로 바뀌어요.

### 조작

| 동작 | 화면 터치 | 키보드 |
|---|---|---|
| 왼쪽 계단 | 아래 왼쪽 버튼 | `←` 또는 `A` |
| 오른쪽 계단 | 아래 오른쪽 버튼 | `→` 또는 `D` |
| 어림 돋보기 쓰기 | 화면 오른쪽 아래 아이템 버튼 | `1` |
| 멈춤 시계 쓰기 | 화면 오른쪽 아래 아이템 버튼 | `2` |
| 다음 화면 / 다시 시작 | 버튼 | `Enter` |
| 창 닫기 | 닫기 버튼 | `Esc` |

## 시작하기

1. 첫 화면에서 **플레이어**(별명)를 확인하고 **▶ START**를 눌러요.
2. **준비 1/2**: 캐릭터와 레벨을 골라요.
3. **준비 2/2**: 여유 모드를 켤지 정하고, 가져갈 아이템을 고르거나 그 자리에서 사요. 그다음 **▶ 출발!**

게임이 끝나면 **다시 오르기**(같은 설정으로 바로 시작), **설정 바꾸기**, **처음으로** 중에 고를 수 있어요.

## 레벨 (19단계)

레벨은 2022 개정 교육과정 '수와 연산' 순서를 따라요. 처음에는 Lv.1만 열려 있고, **한 레벨에서 10층에 오르면 다음 레벨이 열려요.**
별은 레벨마다 ★ 10층, ★★ 20층, ★★★ 30층이에요. 모든 답은 0 이상의 자연수예요.

| Lv | 내용 | 학년 수준 | 예시 |
|---|---|---|---|
| 1 | 9까지의 덧셈 | 1학년 1학기 | `3 + 5` |
| 2 | 9까지의 뺄셈 | 1학년 1학기 | `8 − 5` |
| 3 | 받아올림·받아내림 없는 (몇)±(몇), 덧셈과 뺄셈 섞기 | 1학년 1학기 | `6 + 3`, `7 − 4` |
| 4 | 10 만들기, 받아올림·받아내림 있는 (몇)±(몇) | 1학년 2학기 | `3 + ? = 10`, `7 + 6`, `13 − 8` |
| 5 | 받아올림·받아내림 없는 (두 자리)±(한·두 자리) | 1학년 2학기 | `23 + 4`, `68 − 23` |
| 6 | 받아올림·받아내림 있는 (두 자리)±(한·두 자리) | 2학년 1학기 | `38 + 47`, `52 − 17` |
| 7 | 덧셈과 뺄셈으로 하는 세 수의 계산 | 1학년 2학기 ~ 2학년 1학기 | `4 + 6 + 3`, `25 + 8 − 6` |
| 8 | 곱셈구구 2단~5단 | 2학년 2학기 | `4 × 7` |
| 9 | 곱셈구구 6단~9단 | 2학년 2학기 | `7 × 8` |
| 10 | 곱셈구구 2단~9단 | 2학년 2학기 | `6 × 9` |
| 11 | 곱셈구구 전체 (1단, 0의 곱 포함) | 2학년 2학기 | `1 × 6`, `0 × 7` |
| 12 | 세 자리 수의 덧셈과 뺄셈 | 3학년 1학기 | `467 + 285` |
| 13 | 나머지가 없는 나눗셈 (곱셈구구 거꾸로) | 3학년 1학기 | `56 ÷ 7` |
| 14 | (두 자리) × (한 자리) | 3학년 1학기 | `47 × 6` |
| 15 | (세 자리) × (한 자리) | 3학년 2학기 | `274 × 7` |
| 16 | (두 자리) × (두 자리) | 3학년 2학기 | `24 × 36` |
| 17 | 몫이 한 자리이고 나머지가 있는 나눗셈 | 3학년 2학기 | `47 ÷ 6 = 7…5` |
| 18 | (두 자리) ÷ (한 자리), 몫이 두 자리 | 3학년 2학기 | `75 ÷ 4 = 18…3` |
| 19 | 자연수의 혼합 계산 (계산 순서와 괄호) | 5학년 1학기 | `9 + 3 × 6`, `(4 + 12) × 7` |

- **★ 도전 모드**는 처음부터 열려 있어요. Lv.1부터 시작해 10층마다 다음 레벨로 넘어가고, 지나간 레벨도 함께 열려요.
- **여유 모드**를 켜면 모든 문제의 시간이 1.5배가 돼요. 여유 모드 기록은 따로 저장돼요.
- 나머지가 있는 나눗셈의 답은 `몫…나머지`로 써요. 예: `7…5`
- 문제마다 생각할 시간이 달라요. 예를 들어 곱셈구구는 4초, (두 자리)×(두 자리)는 20초예요.

### 오답 선택지

틀린 쪽 계단의 답은 아이들이 실제로 자주 하는 실수에서 만들어요.
- 덧셈·뺄셈: 받아올림을 깜빡한 값(±10), 1~2 차이 나는 값
- 곱셈구구: 옆 단의 값 (예: `7 × 8`이면 63이나 48)
- 큰 수 곱셈: 자릿값 실수 (±10, ±100)
- 나머지가 있는 나눗셈: 몫이나 나머지가 1 다른 값
- 혼합 계산: **계산 순서를 무시하고 앞에서부터 계산한 값** (예: `9 + 3 × 6`이면 함정은 72, 정답은 27)

## 보스

**10층마다 보스가 나와요.** 간판이 빨갛게 바뀌고 보스 체력 3칸이 보여요.
보스 문제는 같은 레벨의 **응용 문제**예요. 3문제를 맞히면 보스가 떨어지고 **보물 코인 3~5개**를 얻어요.

| 레벨 | 보스 문제 예시 |
|---|---|
| 덧셈·뺄셈 | 빈칸 찾기 `? + 6 = 13` |
| 곱셈구구 | 거꾸로 구구 `? × 8 = 56` |
| 나눗셈 | `? ÷ 7 = 8`, 검산 `6 × 7 + 5 = ?` |
| (세 자리)×(한 자리) | 가운데 0이 있는 수 `408 × 6` |
| 혼합 계산 | 연산이 3개인 식 `9 × (12 − 3) + 16` |

## 코인과 상점

- 가끔(약 10%) **양쪽 계단 모두에 코인**이 떠요. 맞히면 얻어요. 코인은 정답이 어느 쪽인지 알려주지 않아요.
- 아주 빨리 맞히면 가끔 보너스 코인이 나와요.
- 보스를 이기면 코인 3~5개를 얻어요.

정답을 알려주거나 문제를 건너뛰게 하는 아이템은 없어요. 생각할 시간을 주거나 생각을 돕는 아이템만 있어요.

| 아이템 | 가격 | 효과 | 쓰는 때 |
|---|---|---|---|
| 멈춤 시계 | 8 | 5초 동안 시간 게이지가 줄지 않아요 | 게임 중 (한 판에 1번) |
| 어림 돋보기 | 6 | 답의 범위를 알려줘요. 예: "답은 1000~1100 사이" | 게임 중 (한 판에 2번) |
| 자석 | 10 | 그 판에서 코인이 나올 확률이 2배 | 출발 전에 가져가기 |
| 낙하산 | 25 | 한 번 떨어져도 **같은 문제를 다시 풀면** 이어서 올라요. 오답 선택지는 새로 바뀌어요 | 출발 전에 가져가기 (한 판에 1번) |
| 보스 칼 | 12 | 그 판의 보스 체력이 1칸 줄어요 | 출발 전에 가져가기 |
| 캐릭터 (파랑·분홍·노랑·살구 우주인) | 30 · 40 · 60 · 80 | 모습만 바뀌어요 | 상점 |

아이템을 쓴 판은 기록에 "아이템"으로 표시돼요.

## 플레이어 (한 기기를 여러 명이 쓸 때)

- 첫 화면의 플레이어 이름 옆 **[바꾸기]**에서 플레이어를 고르거나 새로 만들어요. 한 기기에 최대 40명까지 만들 수 있어요.
- 새 플레이어의 별명은 "용감한 초록 37"처럼 자동으로 추천돼요. **실명 대신 별명을 써 주세요.** 욕설이 들어간 별명은 쓸 수 없어요.
- 코인, 아이템, 캐릭터, 열린 레벨, 기록, 학습 결과는 **플레이어마다 따로** 저장돼요. 음량 설정만 기기 전체에 공통이에요.

## 내 기록과 학습 결과

- **내 기록**: 레벨별 최고 기록 TOP 10(날짜, 아이템 사용 여부)과 최근 20판 막대그래프
- **게임 오버 화면**: 내 기록 중 몇 위인지, 이번 판에 얻은 코인, **오래 고민한 문제 3개**
- **학습 결과 → 내 결과**: 오늘·전체 푼 문제 수와 정답률, 최근 7일 그래프, 레벨별 정답률·시간 초과 수·평균 풀이 시간, 최근 틀린 문제 10개. 10문제 이상 푼 레벨 중 정답률이 가장 낮은 레벨에 **"연습 필요"** 표시
- **학습 결과 → 이 기기 전체**: 한 기기의 모든 플레이어를 한눈에 (푼 문제 수, 정답률, 열린 레벨, 연습이 필요한 레벨)

틀리면 그 판이 끝나기 때문에 한 판에 틀린 문제는 1개뿐이에요. 정답률과 함께 시간 초과 수를 같이 보세요.

## 학급 랭킹

같은 학급 코드를 입력한 친구들끼리 레벨별 순위를 겨뤄요. 인터넷 연결이 필요해요.

### 선생님

1. 첫 화면 **[학급 랭킹] → "선생님: 새 학급 만들기"**를 눌러요.
2. 학급 이름(선택, 20자까지)과 **관리 비밀번호**(숫자 4~8자리)를 정하면 **6자리 학급 코드**가 나와요. 예: `K7Q2MX`
   - 학급 이름에 학교 이름은 넣지 않는 걸 추천해요. 예: "빵쌤 3-2"
   - **비밀번호는 다시 보여주지 않아요.** 꼭 따로 적어 두세요.
3. 아이들에게 학급 코드를 알려주세요.
4. 랭킹 화면의 **[선생님 관리]**에서 비밀번호를 넣으면 할 수 있는 일:
   - 레벨별 전체 기록 보기
   - 아이별 **숨기기 / 보이기**, **지우기**
   - **아이템을 쓴 기록도 랭킹에 올릴지** 정하기
   - 학급 이름 바꾸기
   - **랭킹 초기화**, **학급 닫기** (코드와 기록이 모두 사라져요)
   - 비밀번호를 5번 틀리면 10분 동안 잠겨요.

### 학생

1. 첫 화면 **[학급 랭킹]**에서 선생님께 받은 코드를 넣어요.
2. "'빵쌤 3-2' (K7Q2MX)에 참여할까요?"가 나오면 우리 반이 맞는지 확인하고 **[네, 참여할래요]**를 눌러요.
3. 게임이 끝날 때마다 기록이 **자동으로** 올라가요. 게임 오버 화면에 "우리 반 랭킹 3위!"처럼 나와요.
4. 랭킹 화면에서 레벨과 여유 모드별 **상위 20명**과 **내 순위**를 볼 수 있어요.

학급은 이름이 아니라 **6자리 코드로 구분**해요. 다른 학교에 같은 이름의 반이 있어도 랭킹은 섞이지 않아요.

|---|---|
| 이 기기에만 저장 | 플레이어 별명, 코인, 아이템, 기록, 학습 결과, 설정 (브라우저 저장소) |

- 브라우저 저장소를 지우면 이 기기의 기록과 코인도 함께 지워져요.

## 설정과 그 밖의 것

- **설정**(첫 화면 [설정] 또는 화면 오른쪽 위 톱니바퀴): 배경음악과 효과음 크기를 0~100% 범위에서 따로 조절해요. 게임 중에 열면 게임이 멈춰요.
- **배경음악**: 첫 화면, 계단 오를 때, 보스전에 각각 다른 곡이 나와요. 소리는 화면을 한 번 누른 뒤부터 나와요.
- **해금 코드**: 첫 화면 아래 "해금 코드 입력"에서 코드를 넣으면 모든 레벨이 열려요. 코드는 만든이와 관련된 이스터에그예요. 🍞

# 개발자용

## 폴더

| 경로 | 내용 |
|---|---|
| `src/game.html` | 게임 원본 (HTML, CSS, JS). 고칠 때는 이 파일만 고쳐요 |
| `assets/` | 스프라이트, 효과음, 배경음악, 글꼴과 각 라이선스 |
| `assets/music-source/` | 배경음악 원본 ogg (m4a로 다시 변환할 때 사용) |
| `build.py` | 원본과 에셋을 하나로 합쳐 `dist/semsem-jump.html` 생성 |
| `tests/check_levels.py` | 19개 레벨의 문제를 대량 생성해 정답·음수·받아올림 조건 검사 |
| `supabase/schema.sql` | 학급 랭킹 데이터베이스(테이블, 접근 규칙, 함수). Supabase SQL Editor에서 실행 |
| `.github/workflows/pages.yml` | `main`에 올리면 검사 → 빌드 → GitHub Pages 배포 |

## 빌드와 검사

```bash
python3 build.py
```

```bash
python3 tests/check_levels.py
```

`dist/semsem-jump.html` 한 파일만 있으면 실행돼요(학급 랭킹만 인터넷 필요). `main` 브랜치에 푸시하면 GitHub Actions가 검사와 빌드를 하고 GitHub Pages에 자동으로 배포해요.

## 학급 랭킹 서버

- Supabase 프로젝트의 SQL Editor에서 `supabase/schema.sql`을 실행해요. 여러 번 실행해도 안전해요.
- 게임은 테이블을 직접 읽거나 쓰지 못하고, 스키마에 정의한 함수만 부를 수 있어요.
- `src/game.html`의 `SB_URL`, `SB_KEY`는 프로젝트 주소와 **publishable(anon) 키**예요. 웹페이지에 공개되는 키예요. **secret(service_role) 키는 절대 넣지 마세요.**

## 배경음악 다시 변환

```bash
afconvert -f m4af -d aac -b 80000 assets/music-source/flowerbed_fields.ogg assets/music/mus_main.m4a
```
